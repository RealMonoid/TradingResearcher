# Rejected, Replaced and Deferred Alternatives

This is a scope-sensitive exclusion register. Rejection of a framework role does not reject every function of that framework. Rejections made by the assistant in the evolving discussion are not represented as verbatim user vetoes. Source links identify the proposer, the qualification/rejection and any subsequent user acceptance. Deferred items are not permanent bans. See [02_DECISION_REGISTER.md](02_DECISION_REGISTER.md) for current authority.
