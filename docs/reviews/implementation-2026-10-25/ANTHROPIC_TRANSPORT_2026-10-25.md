## Investigation and result

Purpose: implement a second real-provider transport behind the current controller, without introducing an agent platform, weakening evidence rules or spending against an unapproved vendor account. The uncertainty was whether Claude's native conversation and usage rules could satisfy the existing exact-profile, bounded-tool and shared-accounting interface. Current official API/model documentation, the existing OpenAI adapter, auxiliary profiles and durable ledger supplied the implementation basis.

The new [Claude Messages adapter](../../../trading_researcher/ANTHROPIC.md) implements the same interface with a dated Sonnet 5.5/API 2026-10-21 configuration. It retains opaque native continuation, groups exact client-tool results, rejects text pretending to be a tool invocation, and accepts final JSON only after a complete final turn. Unknown or truncated outputs cannot grant an accepted research result. Fixed endpoint/TLS, explicit credentials/workspace, response limits, no redirects and no automatic transport retries preserve the owned dispatch boundary.

Accounting reuses the existing SQLite ledger and shared cap. Claude's ordinary, cache-write and cache-read input components are added once; thinking remains an output subset. Unknown or unpriced work retains its reservation. Report schema 3 identifies provider as well as model/version and UTC admission/settlement. The neutral `provider-usage` CLI retains `openai-usage` as an alias. Earlier records and frozen reports are not backfilled or rewritten. No actual Anthropic credential was read or provisioned, and no external inference or token-count request occurred.

The scientific flow remains unchanged: two permitted-context discovery perspectives submit separately; formalization and a separate meaning reviewer preserve the idea; code performs admitted frozen evaluation. A refusal, unavailable model, invalid output or insufficient budget remains a retained operational gap. Different model families do not certify semantic fidelity, independence of errors, research quality or market usefulness.
