The preceding family-series integration exposed a practical storage constraint. This continuation changes transport and redundant serialization while preserving research-contract/1.0: every case, every fixed bootstrap draw, all response identities, original seeds, failures and complete denominators remain required. No estimator, population law, classification, scientific threshold, resource cap or decision changes. Invention, formalization, independent scientific evaluation, policy execution and reporting retain their separate authorities.

## Implementation

New source snapshots write `study-stream-gzip/1` case/draw streams. The format fixes gzip level 6, zero timestamp, no filename or optional header fields, OS byte 255 and 65,536-byte decoded input chunks with a final remainder. Fixed buffering makes encoding independent of caller write boundaries. Both zlib build/runtime versions and exact decoded SHA-256/size accompany the existing encoded blob SHA-256/size. Executed source and Python/standard-library fingerprints remain bound.

Generation and a separate retained-source replay regenerate the same canonical records. Replay recompresses them and compares every encoded byte, including header, footer and exact EOF. The parent separately validates bounded expansion, CRC/length, decoded hash/size and exactly one complete member. Extra members, trailing bytes, changed headers, invalid descriptors and encoding changes between generation/replay fail. Encoded bytes obey the existing four-copy attempt reservation; decoded computation remains capped at 256 MiB independently. Failed encoded prefixes and original raw-format prefix paths remain retained and charged. Failed streams do not write implicitly during object destruction.

The parent still accepts the original five-field raw response and fixed `.jsonl` paths. New responses add an explicit encoding descriptor and use fixed `.jsonl.gz` paths. A captured, hash-pinned source package from `0f1bf368b1709b7e5eb9cf5c54e8f682647fb1da` executes through the new parent in both generation and replay. This exercises that version, not all historical runtimes. Existing final-source currency checks are unchanged; old records are not relabeled as new executions.

Family computations can reuse the estimator's already canonical draw bytes. Response IDs remain JSON-escaped and canonical framing is preserved. The dictionary callback remains available. Arithmetic, randomness, draw counts/order and result fields are unchanged. The standalone population endpoint still uses its existing raw transport.

## Measured comparison and limits

One preselected mixed-truth synthetic family with 64 time rows and two responses executed through both actual source pipelines, including separate-process replay. Both produced identical complete results and all 79,996 draws; the full decoded stream was byte-identical. This is an engineering fixture, not a completed calibration or market-model adequacy test.

| Observation | Retained raw source | New encoded source |
|---|---:|---:|
| One stored stream | 22,787,327 bytes | 4,079,481 bytes |
| Charged materializations, retained outputs and metadata | 93,962,634 bytes | 19,148,378 bytes |
| Paired pipeline elapsed time | 22.873 seconds | 23.006 seconds |

The observed stream is 82.10% smaller and the logical charge is 79.62% smaller. This pair demonstrates no speed gain. Timings include process startup, provenance checks, replay and retention validation; they are not a stable performance distribution. Multiplying the encoded logical charge by 1,024 gives 19,607,939,072 bytes (18.26 GiB), excluding series setup. The analogous elapsed projection is about 6.54 hours. These are extrapolations, not an executed complete workload, and still exceed the unchanged 4 GiB/60-minute limits. No full series was launched on a false feasibility claim.
