The speed objective is compatible with the project; the proposed evidence shortcut and deletion policy are not. The relevant loop is permitted discovery → faithful formalization and freeze → independent evaluation → retained, qualified experience → a later research epoch. Learning from failure belongs in that loop; converting an outcome-selected survivor into “independently confirmed” crosses its boundary.

- **Outcome-dependent rewriting:** Preserve the original frozen claim and result. A revision creates a child hypothesis with inherited exposure, a new trial identity and a new freeze; it is not an execution retry. Replaying the identical frozen request adds no independent evidence (D001, D014, D031; Master Architecture).
- **Repeated holdout reuse:** Feedback makes that holdout exposed for descendants, including through memory. Logging documents contamination and selection; it does not undo either. “Until it succeeds” introduces outcome-dependent selection/stopping that requires an appropriate precommitted evaluation policy. A trial count alone is insufficient. Independent code execution also does not make reused data independent confirmation (REQ-013, REJ-014; Scientific Evaluation).
- **Ambiguous failure:** A valid negative result can eliminate a claim. An inconclusive result, unavailable capability or technical error is different; technical errors provide neither support nor falsification (D007; DEF-017–020).
- **Schema exclusion:** Retain unsupported H_idea records with typed capability gaps and retry conditions. Restrict executable submissions where necessary, but do not discard ideas or silently translate them into convenient different claims. Certified compositions and separately validated extensions preserve free invention (D002–D004, REQ-002–003). Replacing discovery with the current catalog would be **GOAL CHANGE — USER APPROVAL REQUIRED**.

A consistent speed proposal would accelerate both discovery and testing: bounded deterministic queries, pre-freeze counterexamples and feasibility checks can stop weak candidates early; qualified historical experience can guide later search with its exposure intact. Historical-first evaluation avoids waiting years for every useful research decision. Reserve scarce clean confirmation for selected claims through an ex-ante allocation policy; retain evidence-origin qualifications and the distinct role of true forward evidence.

Reduce avoidable engineering work through reusable certified computations, bounded diagnostics, narrow backend adapters and the smallest coherent implementation. Measure cycle time, cost, technical reliability and decision quality together; neither more confirmations nor more rejections proves framework success. Preserve end-to-end null/planted-signal calibration and economic gates.

Exact stopping/error rules, allocation, language semantics and certification authority remain unresolved (OPEN-04–05, 11–12, 14); this assessment does not select them.
