`BoundedReferenceEngine` in `bounded_math.py` adds an exact complete-window trailing median and an outcome-only logarithm. A missing window stays missing. Median ties and even-window averages use exact fractions. Logarithms require a strictly positive dimensionless argument; domain errors remain missing, and unsupported interval decisions/compositions remain typed gaps. Three-valued condition logic is unchanged. The original complete-input unknown rule must be expressed and independently reviewed; a successful type check does not establish faithful meaning.

The logarithm calculation reduces a positive rational to `2^k * r`, with `1 <= r < 2`. It uses the positive-series identity in [NIST DLMF 4.6.4](https://dlmf.nist.gov/4.6.E4), consulted October 29, 2026. The range reduction, outward rounding and tail proof are project derivations. With `z=(r-1)/(r+1) <= 1/3`, the remainder after 64 terms is bounded by `9*z^129/(4*129)`. Integer arithmetic rounds outward on a `2^-128` grid; signed range-reduction factors preserve endpoint order. Limits on input size and primitive steps prevent uncontrolled calculation. Independent Decimal-based checks supplement the reviewed bound derivation; software tests are not a market-validity result.

Conditional and whole-scope means, and their difference, propagate bounds conservatively. Unknown conditions remain in the observed whole-scope denominator. No midpoint replaces the interval.
