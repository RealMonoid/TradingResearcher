It accepts only that pinned prompt/version, preserves all non-prompt formalizer fields and the complete independent review protocol/profile, and returns explicit `PREPARED_NOT_ADMITTED` metadata. No provider, count, epoch, source selector, grant or native operation is invoked.

The old profile explicitly selected H_exec/1, AST1/2 and no absolute value. The new profile selects the already approved scalar H_exec/3 and AST4, adds the four D097 operator fields/constraints and exponent origins, and removes paired/binary branches only from this new scalar profile. Legacy profiles and their bytes remain unchanged. Shared faithfulness/gap, exact original/source/parameter mapping, catalog identity, temporal/availability, whole-scope denominator, numerical enclosure, neutral reporting and compact serialization obligations remain; old paragraphs that apply unchanged are inherited. Complete mathematical/reporting documents are still required in the input.

A later accepted resource revision needs its own explicit profile/source version; it must not mutate a frozen profile or readmit a consumed grant. Model, reasoning, full output allowance and all generation settings—including their original expiry—remain unchanged. Their preservation is not a freshness, pricing or funding check.

`request_candidate(construction, packet)` recomputes the construction, requires a scalar formalization-input/1 packet with complete current exact/reporting owner bytes, and delegates to the existing auxiliary request builder. It creates a request candidate only. Source ownership, complete actual original/feature definitions, authorized context/exposure/data use, fresh provider configuration, full-input counts, original-epoch resource allocation, independently reviewed meaning and native funded admission retain their separate gates. Standalone caller-supplied packet fields grant no permission.

The public baseline fixture preserves the actual old formalizer/reviewer values without credentials. Synthetic transport checks prove exact construction/full input restoration and unchanged settings, not actual model comprehension, success, semantic fidelity, lower token cost or research quality equivalence. The original A null formalization, all failure/exposure history, old source bytes, existing USD5 ledger and seven revoked grants remain unchanged.
